A style option (`Chart(style=...)`) was designed in `notes/styler-sketch.md` (2026-07-22). Implemented so far: `Styler` extracted from Canvas into `styles/styler.py` (canvas owns it, `resolve_color` delegates), settings grammar `<role>[.<variant>].<facet>` (flat dotted keys, facet always explicit — rcParams rule) with `get_setting(name, facet, fallback=)` (None-defers only) and `resolve_color(role, ax, override=, fallback=)` as the full pipeline (chain override → setting → fallback, then cycle/sentinel/hex munging; renamed from `get_color` — it resolves, not looks up); `get_styler(style, overrides=)` — single polymorphic normalizer behind `style=` on Chart/Canvas (None | prebuilt Styler now; specs later); `overrides` = canonical keys. `color_scheme` deprecated 2026-07-23: warn-and-ignore at Chart only, removed from Canvas/get_styler, `map_color_scheme` deleted (playground/color-scheme.ipynb removed with it). Overrides genuinely override every style source, prebuilt Styler included (derived copy, original untouched) — an override layer that rejects some sources is a naming lie. Candlesticks retrofit done 2026-07-23 with the settled key vocabulary — `candle.up/down/off`, `edge.up/down`, `wicks` (all `.color`; `down` not `dn` in settings, kwargs keep `colorup`/`colordn`; edge/wicks are top-level roles, `wicks` deliberately plural; `off` = hollow-body fill, freeing the `hollow` stem for the future bool flag — legacy color_scheme appends `.color` to bare keys, so a stem can't be both flag and color): no-kwargs path resolves those settings (family read off resolved faces: `faceup == facedn` → mono/hollow; edges default to faces, wicks to edges; `candle.alpha` non-color facet — alpha kwarg None-defaults to the setting), kwarg schemes stay atomic via always-set `override=`; tri-state `hollow` kwarg (None → resolved-face default). Consistency checks are params-only (user was explicit: settings/defaults bend to params, never the reverse) — competing schemes at init, explicit mono `color=` vs `use_prev_close`/`hollow=False` at plot time; the default mode is NEVER validated against settings, bare flags render as-is (possibly direction-blind); mode kwargs compose with settings palettes. Done 2026-07-23: rc wiring at choke points (canvas init/panes/plot_indicator/legends/show/render, vline/hline via plot_indicator); `Styler(stylesheet=)` + `load_stylesheet` (stock name, .mplstyle path, or "default" → factory template minus STYLE_BLACKLIST; collapsed eagerly under rcparams — composition lives in ctor/factory, lib modules stay data-only); `DEFAULT_RC` baseline (`axes.grid` True, `grid.alpha` 0.4 — default look as rc, layered under every styler) with canvas grid config reading `axes.grid`/`axes.grid.axis` instead of hardcoding. mplfinance emulation gotchas: mpf style names ≠ their base sheets (mpf "classic" bases on "fast"), and their `explicit_grid` rule (any grid field → grid on) lives in the notebook translator. Mode flags done 2026-07-23: `candle.hollow`/`candle.use_prev_close` settings — bool kwarg mirrors (chain kwarg → setting → default; `use_prev_close=` kwarg now `None`-defaults; the `candle.scheme`/`colorby` enum sketches are superseded — settings mirror params in name and type, like `candle.alpha`; non-color settings ride via `style=` only, `color_scheme=` munges bare keys with `.color`). Not yet: `Style` spec + `resolve_style` (to go in `styles/style.py`), `styles/lib/`, OHLC/Volume retrofit.

Key decisions (rationale in the note): `Style` frozen dataclass (rc + symbolic colors) and `Styler` runtime (cycles, sentinels, rc context) in a new `mplchart.styles` package with shipped styles as zero-import `STYLE` dict modules under `styles/lib/` (directory = registry, lazy import). Styler nests inside Canvas behind the `resolve_color` facade — primitive contract otherwise unchanged. Core invariants: no style state survives to draw time (rc via scoped `rc_context` at creation choke points; symbolic colors resolved eagerly to hex); named-color-registry and CN-cycle hacks were investigated and rejected (draw-time resolution — verified empirically).

Coverage validated 2026-07-23: `playground/candlesticks-styles.ipynb` emulates all 16 mplfinance styles via a marketcolors→settings translator prototype + scoped `rc_context` (stand-in for pending rc wiring) — candle settings surface is complete.

Candidate settings vocabulary lives in `notes/style-settings.md` — singular roles (`candle.up.color`, not `candles.*`), full mplfinance coverage accounting, per-primitive keys with today's defaults. Candlestick scheme taxonomy in `notes/candlestick-styles.md` — four families (mono hollow / two-color filled / yahoo-style neutral wick / colored hollow) over the six-color `plot_cspoly` surface (face/edge/wick × up/dn; wicks are a separate LineCollection).

Prior art in git history: deleted `stylemap.py` / `stylesheet.py` / `stylesheets/*.ini` (early attempts; `Canvas.resolve_color`, né `get_color`, is stylemap's distilled survivor). mplfinance was inspected as reference (mutates rcParams globally without restore; its clean fix exists commented-out in its source).
