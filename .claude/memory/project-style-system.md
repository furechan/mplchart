**Single style object (2026-07-31, supersedes the Style/Styler split below):** the frozen `Style` spec and `make_style` (né `resolve_style`) were REMOVED in a stepwise user-driven refactor — `Styler` is the one style object. `get_styler` (styler.py) dispatches specs — `Styler.from_spec` for mappings, `resolve_style` for names: shipped name → mpl sheet name → `provider:` prefix ("mpf:yahoo"/"mt:economist" via `ENTRY_POINTS` in styler.py, lazy loader import) → mapping (`stylesheet`/`rc`/`settings`/`aliases`, eager rc validation via `mpl.RcParams` round-trip). `style.py` is DELETED — the registries live in `registry.py` (`ENTRY_POINTS`, `available_styles`); `stylesheet.py` = matplotlib layer (`base_template`, `load_stylesheet`, `STYLE_BLACKLIST`). Provider loaders (`styles/mplfinance.py` `load_mpf_style`, `styles/morethemes.py` `load_mt_theme`) build `Styler` directly, import their package only inside the function (zero blast radius, pinned by test_provider_packages_have_zero_blast_radius); the flat-namespace morethemes hook was removed (mpf names collide: nightclouds/classic/default). Styler carries no display name. Historical mentions of `Style`/`resolve_style` below predate this.

The style system (`Chart(style=...)`) was designed in `notes/styler-sketch.md` (2026-07-22) and fully implemented over that week (shipped 0.0.41+). Record of what landed and the doctrine behind it: `Styler` extracted from Canvas into `styles/styler.py` (canvas owns it, `resolve_color` delegates), settings grammar `<role>[.<variant>].<facet>` (flat dotted keys, facet always explicit — rcParams rule) with `get_setting(name, facet, override=, fallback=)` (override → setting → fallback, None-defers only; resolve_color delegates to it) and `resolve_color(role, ax, override=, fallback=)` as the full pipeline (chain override → setting → fallback, then cycle/sentinel/hex munging; renamed from `get_color` — it resolves, not looks up); `get_styler(style, overrides=)` — single polymorphic normalizer behind `style=` on Chart/Canvas (None | prebuilt Styler now; specs later); `overrides` = canonical keys. `color_scheme` deprecated 2026-07-23: warn-and-ignore at Chart only, removed from Canvas/get_styler, `map_color_scheme` deleted (playground/color-scheme.ipynb removed with it). Overrides genuinely override every style source, prebuilt Styler included (derived copy, original untouched) — an override layer that rejects some sources is a naming lie. Candlesticks retrofit done 2026-07-23 with the settled key vocabulary — `candle.up/down/off`, `edge.up/down`, `wicks` (all `.color`; `down` not `dn` in settings, kwargs keep `colorup`/`colordn`; edge/wicks are top-level roles, `wicks` deliberately plural; `off` = hollow-body fill, freeing the `hollow` stem for the future bool flag — legacy color_scheme appends `.color` to bare keys, so a stem can't be both flag and color): no-kwargs path resolves those settings (family read off resolved faces: `faceup == facedn` → mono/hollow; edges default to faces, wicks to edges; `candle.alpha` non-color facet — alpha kwarg None-defaults to the setting), kwarg schemes stay atomic via always-set `override=`; tri-state `hollow` kwarg (None → resolved-face default). Consistency checks are params-only (user was explicit: settings/defaults bend to params, never the reverse) — competing schemes at init, explicit mono `color=` vs `use_prev_close`/`hollow=False` at plot time; the default mode is NEVER validated against settings, bare flags render as-is (possibly direction-blind); mode kwargs compose with settings palettes. Done 2026-07-23: rc wiring at choke points (canvas init/panes/plot_indicator/legends/show/render, vline/hline via plot_indicator); `Styler(stylesheet=)` + `load_stylesheet` (stock name, .mplstyle path, or "default" → factory template minus STYLE_BLACKLIST; collapsed eagerly under rcparams — composition lives in ctor/factory, lib modules stay data-only); `DEFAULT_RC` baseline (`axes.grid` True, `grid.alpha` 0.4 — default look as rc, layered under every styler) with canvas grid config reading `axes.grid`/`axes.grid.axis` instead of hardcoding. mplfinance emulation gotchas: mpf style names ≠ their base sheets (mpf "classic" bases on "fast"), and their `explicit_grid` rule (any grid field → grid on) lives in the notebook translator. Mode flags done 2026-07-23: `candle.hollow`/`candle.use_prev_close` settings — bool kwarg mirrors (chain kwarg → setting → default; `use_prev_close=` kwarg now `None`-defaults; the `candle.scheme`/`colorby` enum sketches are superseded — settings mirror params in name and type, like `candle.alpha`; non-color settings ride via `style=` only, `color_scheme=` munges bare keys with `.color`). Style spec done 2026-07-23: `styles/style.py` — frozen `Style` (rc validated eagerly via `mpl.RcParams` round-trip), `resolve_style(name | mapping | Style)` with the `stylesheet` dict key (spelling supersedes draft `base_mpl_style`), `available_styles` (pkgutil over `styles/lib/`); `load_stylesheet` moved to style.py so the static layer imports nothing from the runtime layer; `Chart(style="name")` works. Shipped styles (renamed 2026-07-24 to descriptive, trademark-free names): `mplchart` (default look), `modern` (né tradingview), `nightclouds`, `chartist` (né stockcharts, mode flags in-style); trademark disclaimer in styles/lib/__init__.py + docs-requirements section of the sketch. OHLC retrofit done 2026-07-23: `ohlc.up/down.color` + `ohlc.alpha` (per-side params — kwarg → setting → textcolor, NOT atomic: no coordinated look to protect, unlike candle schemes; no anatomy/mode flags — interbar criterion is the chart type's definition; roles independent of `candle.*`, shipped styles declare both palettes). Volume retrofit done 2026-07-23: `volume.up/down/ma.color` + `volume.alpha` (per-element like OHLC; fallbacks `~green`/`~red`/`~gray` keep the snap, explicit kwargs now exact — the old code snapped user colors through closest_color, a quirk fixed; direction now intrabar close ≥ open matching candles, was interbar). Primitive retrofit arc COMPLETE — remaining styling ideas live in the notes/backlog only.

Key decisions (rationale in the note): `Style` frozen dataclass (rc + symbolic colors) and `Styler` runtime (cycles, sentinels, rc context) in a new `mplchart.styles` package with shipped styles as zero-import `STYLE` dict modules under `styles/lib/` (directory = registry, lazy import). Styler nests inside Canvas behind the `resolve_color` facade — primitive contract otherwise unchanged. Core invariants: no style state survives to draw time (rc via scoped `rc_context` at creation choke points; symbolic colors resolved eagerly to hex); named-color-registry and CN-cycle hacks were investigated and rejected (draw-time resolution — verified empirically).

Coverage validated 2026-07-23: `playground/candlesticks-styles.ipynb` emulates all 16 mplfinance styles via a marketcolors→settings translator prototype + scoped `rc_context` (stand-in for pending rc wiring) — candle settings surface is complete.

AutoPlot delegation DONE 2026-07-23: renderers accept concrete data — `view.eval` adopts array-likes per backend (pandas reindexes date-indexed data to the prices index; positional must be full-length; the VIEW owns alignment/munging, primitives never learn internals — user was explicit), `get_label` reads series `.name`, `chart.plot(series)` dispatches, `line_style` metadata hook + `get_metadata` removed (CMF now a line). AutoPlot = pure dispatcher (`*hist` → BarPlot alpha 0.5 width 0.8, band cols → Bands, else LinePlot); styling lives in the renderers keyed by label/series name — COMPOUND KEYS REJECTED (user was explicit: no `macd.signal.color`, no `role=` param for now; flat `macd`/`macdsignal`/`macdhist` keys, series name is the styling key). Legend suppression via `legend=` bool on renderers + Bands (sentinel munging rejected — label keeps ONE meaning: legend text and styling key; resolve runs on the full label before legend gating). New `Bands(indicator, upper=, middle=, lower=)` primitive (band-column names configurable; colors via the fixed `bands.color` key — not the indicator label; per-band keys like `bands.upper.color` deferred). Explicit LinePlot/Area/Bar now honor settings + empty-pane text.color — the AutoPlot-only asymmetry from primitive-contract.md is closed.

TOTAL STYLES settled 2026-07-24 (supersedes ambient-adaptivity + DEFAULT_RC + sheet-name-rejection): every styler totalized over `base_template()` (rcParamsDefault minus STYLE_BLACKLIST minus ENVIRONMENT_KEYS = figure.dpi/savefig.dpi which stay ambient); NO ambient inheritance (charts identical everywhere — mplfinance totality without global mutation); DEFAULT_RC deleted — the default look is the shipped `mplchart` lib style (template + axes.grid True + grid.alpha 0.4), resolved when style=None; bare style ⇒ bare gridless chart (documented, two keys to know); matplotlib sheet names accepted as styles (`style="ggplot"` = the sheet's complete look, lib shadows); external providers: morethemes themes resolve by name when installed (resolution order lib → sheets → providers; optional import, dev dep only); Styler(settings=...) alone is total-bare — use get_styler("mplchart", overrides=settings) for default-look-plus-settings. Perf after totalization: ctor 77µs, context 233µs, chart ~7.5ms (~10% over) — acceptable, no caching.

Primitive styling maturity model settled 2026-07-24 (recorded in styler-settings.md doctrine): basic → style kwargs → fully stylable; primitives advance on demand/priority, never as a sweep. Decorations (Stripes/Markers/Swings/TrendLines/ZigZag) sit at stage 2; HLine/VLine stay rc-tied by design.

Role sanitization settled 2026-07-24: get_setting/resolve_color sanitize via extract_prefix up front — ONE lookup on the canonical key ("a key is a key, not a label" — user was explicit); raw-label keys dead (doctrine: roles never instances); list cycles key per (ax, canonical key) so SMA(20)/SMA(50) share the sma cursor (the mavcolors-fragmentation bug, fixed); `extract=False` opt-out on both accessors + canvas facades. Backlog extract_prefix item completed.

Indicator styling doctrine settled 2026-07-23 (recorded in `notes/styler-settings.md`): styles style roles never instances; `axes.prop_cycle` = the anonymous-line palette (the mavcolors generalization — NOT list-valued sma.color, which fragments per prefix); identity via the label channel (expression factories alias conventionally, `SMA(20)` → 'sma-20' → role sma; unnamed exprs = anonymous → cycle — naming is the styling opt-in); first line on empty pane (`ax.has_data()`, was legend-handles) = text.color.
